# dPrinceofPersia

A playable browser remake of the classic *Prince of Persia* (1989): open `index.html` in any browser.

- Run, standing/running jumps, ledge grab and climb, falling damage
- Spike traps, pressure plate + gate, healing potions
- Sword fights with guards (strike with Space, block with Down)
- 60-minute countdown, a 3-screen dungeon level with an exit door

Controls: Arrows/WASD to move, Up to jump (hold Up in the air to grab ledges, Up again to climb, Down to drop), Space to strike, Enter to start/restart.
